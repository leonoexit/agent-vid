# Generate pieces that can participate

Use the imagegen skill's built-in tool. Save original outputs locally with exact prompts, references and hashes. Transparent objects need real alpha; inspect on the final fields. The reference establishes palette/treatment, not the subject for every video.

Derive assets from the joint image/typography storyboard before HTML positions: subjects, people/gestures, physical actions, relevant places as foreground inserts, mechanism details, comparison views and independent parts/states. Give each selected image a clear explanatory or compositional role. Add authentic sourced evidence when needed. Expressive titles, comparison labels and text-bearing paper families are equal design resources when they establish hierarchy or communicate an idea efficiently. Use native SVG/HTML when exact geometry or editable data is needed, but stage it as part of the same collage ensemble; implementation medium does not determine whether it moves.

For an isolated object: request convincing photographic detail, monochrome/duotone print treatment in the chosen palette, narrow white irregular paper contour, complete functional silhouette, transparent margins and no external baked shadow. Specify exact text or no text. A production role name must never turn into an unrequested heading. Preserve internal material shading.

For an expressive headline, label or compact takeaway: supply the exact short wording with accents, irregular painted/condensed lettering and the desired paper silhouette. Use a text-bearing piece for expressive fixed wording. For frequently changing copy, a reusable designed paper backplate with an explicit safe text area can carry native lettering; keep that lettering integrated with the plate’s scale, angle and material. A plain empty sticker should not automatically replace a more expressive integrated headline. Generate separate pieces if words need independent choreography. Finite authored states can be matched generated variants using the accepted master as an actual reference; a changing number is not automatically native.

If a hand must release a key or a mechanism must separate, request independent parts; one composite bitmap cannot do that. Photos can identify a subject while exact native geometry explains its behavior. Keep the boundary visible in the source/review: illustrative imagery does not prove historical details.

Check spelling, alpha, halftone at phone size, anatomy, cast-shadow edges and overlap. Use `.paper-label` for generated text-bearing paper; `.photo` for already-bordered photographic cutouts. Avoid double contours/shadows. Store originals unchanged and use CSS transforms for staging.

## Coverage, not a fixed trio

A hero, a hand and a title are possible roles, not a default three-image inventory or stopping rule. For each storyboard passage, identify the subject, useful detail/view, text piece, separable moving parts and required visual states. Reuse an accepted anchor when its identity persists; generate missing views or complete a matched family when the explanation needs them. Three completed images do not justify replacing the remaining planned image roles with generic HTML. Conversely, do not generate filler to reach a minimum count. Record the selected role and the scene that uses it in the asset manifest.

Editable headlines, labels and compact statements can use the included [backplate library](backplates.md). The availability of paper containers is not a reason to convert explanations into text cards. This does not replace authored generated headlines or independent subject images. A small library is a starting vocabulary, not the ceiling for the film.

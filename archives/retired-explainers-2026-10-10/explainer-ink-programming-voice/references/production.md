# Existing voice and HyperFrames production

Work from the AgentVid repository. `<skill>` means this skill directory. `<pipeline>` means sibling `explainer-bento-programming-voice`; its installed voice and synchronization utilities are a required dependency. Reuse those utilities, not its visual template, validator or action-density expectations. A calm page is valid when it gives the viewer useful evidence to inspect; neither handwriting nor caption changes substitute for explanatory visuals.

1. Activate `source scripts/activate.sh`. Create a fresh project with `python <skill>/scripts/new-project.py projects/ink-story/<slug>`. Add `--canvas` for a persistent paper example with guided camera travel (see canvas-story.md). It refuses to replace an existing directory. Copying the bundled cache example is scaffolding, not completion of the user's topic.
2. Write `storyboard.md` and the actual `script.json`, adapting language/audience/code semantics. The copied `voice.json` defaults to Vietnamese Hải Đăng and English Kokoro. Honor explicit/stored choices. Style with the supplied native template and local fonts; choose write/reveal/annotate/hold per beat and create Corporate Memphis assets under `assets/illustrations/` when the storyboard needs them, following memphis-assets.md. Use handwriting.md for the default practical pen effect. Record and verify source-dependent claims. Use staging-and-tempo.md to plan illustration roles and native diagram changes during the core explanation; use the executable diagrams in visual-kit.md where suitable and extend native layouts for other relationships. Preserve the voice default (speed 1.0, paragraph_gap 0.2) unless the brief or a reviewed recording calls for another pace. Do not slow every beginner video automatically.
3. Run `python <skill>/scripts/validate-script.py --project <project>`. It checks data, spoken phrases and local image paths, not instructional quality or overflow.
4. Generate narration with `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'` for the Vietnamese default. For English omit the Vietnamese voice override and use the established settings' Kokoro path. Then run `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. These shared utilities consume intro/scenes/outro and produce audio, word timing, `project-data.js` and audio tags; no Bento entity model is needed. If the dependency is missing, report it instead of creating another engine. Add music only if appropriate, keeping it beneath speech.
5. For a silent layout-only preview, run sync with `--music-only --no-bgm`. This uses estimated reading/reveal timing; it is not a narrated deliverable. VieNeu `monotonic-v2` word timing is a pause-assisted estimate even when audio files exist; it is not forced alignment. Verify key content cues against the audio, using measured local `at` values when needed; report any unverified alignment. After changing narration, regenerate voice/timing. After screen-only edits, rerun sync so project-data.js matches script.json.
6. Inspect representative timestamps and transitions through the paused `window.__timelines['ink-story']`. Wait for timeline registration after fonts/images have loaded. For canvas projects, inspect INK_REVIEW and sample every scheduled hand job in the viewport; do not mistake three scattered gestures for continuous handwriting direction. Check hand travel and withdrawal, readable writing duration, local font load (including Vietnamese accents), page overflow, comparison labels, image crops, reading order, actual cue alignment and caption collisions at phone scale. Inspect forward/backward seeks and page boundaries. Check the next visual focus does not appear while the hand is still writing a previous idea. Measure scene-end silence and longest unchanged main-content intervals; reduce redundant copy/holds when they serve no reading or prediction task. “Read the conclusion” alone does not justify padding every scene. Listen to the final voice where possible; disclose when you cannot. Do not mark a clip comprehensible solely from motion counts or stills.
7. Run `hyperframes lint <project>` and `hyperframes check <project>`; resolve relevant problems. Render `hyperframes render <project> --quality high --output <project>/renders/<slug>-9x16.mp4`. Confirm 1080×1920/30 fps, duration, audio and full decode. Deliver the MP4 with any real review limitations.

The bundled native template has statement, comparison, example, illustration and rule layouts; native-font continuous masked text reveals with a bundled photoreal PNG pen-hand overlay for short headings and explicitly selected text/note blocks, automatic ordinary reveals for long/crowded writing cues, ordinary code/result/image reveals, word-timed captions, and row/tree/loop/cards diagrams with focus, value updates and shared-pen annotations. `window.INK_REVIEW` records pen spans and crowded-cue fallbacks for review. It does not verify acoustic alignment. Corporate Memphis generation guidance is included; the generated hand cutout is bundled, but no Memphis illustration family is bundled. It is a production starting point, not a finished topic-to-video service. The original creation specimen was silent; subsequent project review notes identify actual narrated tests and their limitations.

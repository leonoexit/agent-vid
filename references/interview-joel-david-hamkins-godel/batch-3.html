Definition

Một quy trình máy móc, hữu hạn để giải quyết vấn đề.

Giống như nướng bánh, hoặc kiểm tra xem một số có phải là số nguyên tố không. Nếu bạn có thể viết thành code, đó là một thuật toán.

// Prime Checker
function check(n) {
  if (n < 2) return false;
  for (i=2; i*i<=n; i++) {
    if (n % i == 0)
      return false;
  }
  return true;
}

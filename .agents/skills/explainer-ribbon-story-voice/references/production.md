# Produce with the existing HyperFrames workflow

`<skill>` is this directory; `<pipeline>` is sibling explainer-bento-story-voice. That sibling's TTS and synchronization helpers are an explicit dependency. The visual template and narrative are independent. If the dependency is unavailable, report it rather than creating a new engine. Use the repository runtime, not Remotion.

1. From repository root, `source scripts/activate.sh`. Create `python <skill>/scripts/new-project.py projects/ribbon-story/<slug>`. The helper refuses existing destinations. Replace the bundled worked example with the requested subject and audience.
2. Write a phrase-to-picture storyboard and actual script. Choose the visual anchor, compositions and asset roles alongside narration. Read asset-generation before generating; use the imagegen skill/tool, save selected outputs into the project, preserve alpha and provenance. The workshop sample is appropriate only where its transformation metaphor fits.
3. Run `python <skill>/scripts/validate-script.py --project <project>`. Verify code/results separately. Inspect images on the actual background: dark-green illustrations need ivory/pink or an intentional light inset to retain their silhouette against evergreen.
4. Vietnamese default: `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'`. Honor explicit/stored choices. For English use the established Kokoro setting without the Vietnamese override. Run `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. Narration changes require regenerating voice/timing; screen-only script changes still require resyncing project-data.js.
5. A layout-only preview can use sync with `--music-only --no-bgm`; label it as silent/estimated. Inspect via `window.__timelines['ribbon-story']`. Preview the native before/change/after and verify reverse seeks. Check text/alpha/contrast/cropping, model cues and whether decoration overlaps evidence. Avoid substituting motion quotas for comprehension.
6. Run `hyperframes lint <project>` and `hyperframes check <project>` and resolve relevant issues. Decorative ribbons intentionally extend beyond the canvas and are marked accordingly; the known nested-composition editor warning may remain. These exceptions do not waive clipped text or runtime errors.
7. Render `hyperframes render <project> --quality high --fps 30 --output <project>/renders/<slug>-9x16.mp4`. Confirm dimensions, duration, audio and full decode. Listen to critical cue boundaries where possible and report any real review limits. Deliver the video, not only a still/style specimen, when a video was requested.

Creating this skill includes a generated asset and silent layout/runtime checks, not a finished narrated video or demonstrated effectiveness across arbitrary topics. No new full test is implied merely by maintenance work.

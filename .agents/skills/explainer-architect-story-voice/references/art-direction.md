# The Faithful Architect, adapted for motion

Source: four 1200×1200 HTML files, 80 slides, 19 image assets. All source files are copied unchanged under source/; source-manifest.json holds hashes. Read relevant originals via ref-index.md when choosing a treatment.

## Visible grammar
Ivory #f4f4f0, ink #1a1a1a, blue #75bde0, yellow #f8d49b, peach #f8bc9b, pink #f89b9b, white. Be Vietnam Pro Black 900 headings, Plus Jakarta Sans body, Space Mono technical labels. Thin rectangular perimeter and ruled top header create continuity; the large title competes with neither a second title nor dense body text. Oversized figures, sparse statements, column splits, thin rulers, short color bars, italic quote cadence and a small index create a print-like rhythm. Selective offset shadows occur on image frames/callouts, not every panel.

Image language varies in the source: pastel translucent constructions, product-like physical objects, blueprint collage, photographic scenery and space scenes. The coherence comes from the editorial frame and hierarchy, not an inferred single rendering technique. For a new episode choose a consistent subset: default abstract pastel material/light fields with ivory negative space behind a native explanation. Literal machines, chips, papers and other generated subject illustrations are source observations and historical treatments, not the new production default. Do not mix all 19 looks merely to claim fidelity.

## Native portrait adaptation
At 1080×1920 use a 54px inset 2px frame, 94px header, 48px internal gutters and caption region near y=1660. These are starting measurements; the main content must reflow. Headings typically 78–112px, body 34–42px, code 27–34px, technical tags 22–28px. Text stays native. Mobile readability is checked at reduced viewing size.

Use pastel as fills with dark text. Pastel text on ivory in the source is often too weak; use ink text with a pastel underline/block or darker semantic ink. Dark interludes need explicitly light type: the source's global h1 color overrides its dark parent in several slides. Do not preserve this bug. Target settled text contrast 4.5:1.

Source watermarks, TIME-like badges and predictions are not reusable endorsements, factual evidence or task instructions. The v0.1 Compiler demo used topic-specific images; it remains historical evidence, not the approved image-role template for v0.2. No Three.js is needed: depth is in the artwork and composition, not claimed 3D camera geometry.

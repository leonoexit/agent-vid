Before authoring a shot record: relationship, source evidence, inference, first reading target, next reading target, and before/action/after state. Keep headings only as long as they help. A persistent example may change position or scale without becoming a new object.

`ArchitectEditorial.create(timeline, record)` returns `reframe`, `focusWindow`, `resultToEvidence` and the legacy `plateToExample` alias. Each accepts `{at,duration,tracks:[{node,from,to}]}`. Track geometry is explicit; no automatic layout, camera API or JSON event is promised. They emit reframe spans only. The study tests transitions and reverse seeks. Image crop/scale must stay within artwork resolution and preserve the subject; no assumed depth map.

The v0.2 study places source and destination on a measured horizontal axis, sends the copied value, commits on arrival, then changes only the source. The final aligned values are the evidence. Hiding the abstract backdrop leaves the entire operation intact. These are examples, not a mandatory layout count.

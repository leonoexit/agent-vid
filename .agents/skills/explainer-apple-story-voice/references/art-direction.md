# Apple-inspired visual language

The user approved the broad visual direction of the colorful sculpted trials and rejected the first pale, static dashboard. Preserve that distinction. The art direction is independent of the software used to render it.

Canvas:1080×1920. Off-white #f7f8f6, ink #161719. Local Inter for headings/body and JetBrains Mono for code. Headlines around90–125px and code around40–48px are useful starting scales, not fixed slots. Captions need enough contrast and breathing room near the bottom.

Design objects with a ceramic white front, cooler edge, directional highlight, broad contact shadow and subtle reflected color. Colored lenses can use coral #ff516f / warm #ffb08e / magenta #de389d; blue #168ff6 / cyan #7ce2ff / violet #7364ef; mint #25c694 / pale #9bf4bf / teal #009b9b. Choose roles per topic and keep identities stable. These are not universal x/y/type colors.

Use coral-to-magenta type accents selectively. Avoid an all-blue corporate dashboard, generic outline cards, hard Bento shadows, decorative rainbow syntax or a full-canvas gradient that competes with the data. High contrast, distinctive silhouettes and visible materials matter more than the number of effects.

The visual kit implements these materials with native CSS and inline SVG. It may be adapted into files, items, controls, routes, gates or other meaningful objects. Do not force all concepts into round number badges. When a native asset looks unconvincing, improve its proportions and lighting or choose a better medium; a new rendering engine is not the next design step.

Source contact sheets show several visual families: feature icons, typography, interface demonstration, overview/detail, device framing. Adopt only those useful for the current explanation. No Apple font distribution, Apple logo, OneNotch branding or copied marketing claim is included.

# Existing voice and HyperFrames production

Work from the AgentVid repository. `<skill>` means this skill directory. `<pipeline>` means sibling `explainer-bento-story-voice`; its installed voice and synchronization utilities are a required dependency. Reuse those utilities, not its visual template, validator or action-density expectations. A calm readable page is valid here.

1. Activate `source scripts/activate.sh`. Create a fresh project with `python <skill>/scripts/new-project.py projects/ink-story/<slug>`. It refuses to replace an existing directory. Copying the bundled cache example is scaffolding, not completion of the user's topic.
2. Write `storyboard.md` and the actual `script.json`, adapting language/audience/code semantics. The copied `voice.json` defaults to Vietnamese Hải Đăng and English Kokoro. Honor explicit/stored choices. Style with the supplied native template and local fonts; create assets under `assets/illustrations/` only when the storyboard needs them. Record and verify source-dependent claims.
3. Run `python <skill>/scripts/validate-script.py --project <project>`. It checks data, spoken phrases and local image paths, not instructional quality or overflow.
4. Generate narration with `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'` for the Vietnamese default. For English omit the Vietnamese voice override and use the established settings' Kokoro path. Then run `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. These shared utilities consume intro/scenes/outro and produce audio, word timing, `project-data.js` and audio tags; no Bento entity model is needed. If the dependency is missing, report it instead of creating another engine. Add music only if appropriate, keeping it beneath speech.
5. For a silent layout-only preview, run sync with `--music-only --no-bgm`. This uses estimated reading/reveal timing; it is not a narrated deliverable. After changing narration, regenerate voice/timing. After screen-only edits, rerun sync so project-data.js matches script.json.
6. Inspect representative timestamps and transitions through the paused `window.__timelines['ink-story']`. Check local font load (including Vietnamese accents), page overflow, comparison labels, image crops, reading order, actual cue alignment and caption collisions at phone scale. Inspect forward/backward seeks and page boundaries. Listen to the final voice where possible; disclose when you cannot. Do not mark a clip comprehensible solely from motion counts or stills.
7. Run `hyperframes lint <project>` and `hyperframes check <project>`; resolve relevant problems. Render `hyperframes render <project> --quality high --output <project>/renders/<slug>-9x16.mp4`. Confirm 1080×1920/30 fps, duration, audio and full decode. Deliver the MP4 with any real review limitations.

The bundled native template has statement, comparison, example, illustration and rule layouts; simple phrase reveals; and word-timed captions. It is a production starting point, not a finished topic-to-video service. No complete narrated test video was produced merely to create this skill.

# Production with the existing runtime

`<skill>` is this skill directory. `<pipeline>` is installed sibling `explainer-bento-story-voice`. The local template is independent of its layout/schema; only its existing TTS and synchronization utilities are reused. If that dependency is unavailable, report it instead of inventing a rendering pipeline. HyperFrames and the repository voice runtime remain the production tools.

1. From repository root, `source scripts/activate.sh`. Create a new project with `python <skill>/scripts/new-project.py projects/code-noir/<slug>`. Existing destinations are refused. The starter includes local fonts, GSAP, CSS/JS, voice settings and a Python example script.
2. Author the actual storyboard and script for the user's topic/audience. Read narrative and art direction. Verify any executable example, label real outputs versus explanatory values, and record external sources when relevant. The template's Python story is scaffolding, not the requested finished video.
3. Run `python <skill>/scripts/validate-script.py --project <project>`. Check layout visually; schema success alone does not certify syntax correctness, timing or text fit.
4. Vietnamese default: `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'`. Honor explicit/stored voice choices. English uses the established Kokoro settings; omit the Vietnamese override. Then `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. This writes audio tags and project-data.js from intro/scenes/outro without requiring Bento entities or phases.
5. A silent layout preview can use sync with `--music-only --no-bgm`; label it accordingly. After narration edits regenerate audio/timing; after visual script edits rerun sync. Estimated word timestamps require review, not claims of exact synchronization.
6. Inspect representative shots, code changes, visual-anchor changes, late result reveals, caption safety and backward seeks via the paused `window.__timelines['code-noir']`. Essential text should meet 4.5:1 contrast. Check Vietnamese glyphs and monospace line lengths. Listen at transitions and important cue boundaries when possible; disclose unreviewed audio.
7. Run `hyperframes lint <project>` and `hyperframes check <project>` and resolve relevant findings. The shared single-composition structure may produce the known nested-structure editor warning; runtime/layout failures are not waived. Text stillness while explaining visible evidence is acceptable, so do not inherit Bento's visual-operation quota or fabricate events to satisfy an audit.
8. Render `hyperframes render <project> --quality high --output <project>/renders/<slug>-9x16.mp4`. Verify portrait dimensions, 30 fps, duration, audio and full decode. Deliver the MP4 with actual QA limits.

The supplied starter provides semantic text/code spans, phrase reveals, explicit code/output labels, five layout options and word-timed captions. It is not a full IDE simulation. A skill-creation specimen is not a reviewed narrated video and does not establish quality across all topics.

For visual-led beats, use `assets/js/noir-visuals.js` alongside the existing paused timeline. New-project copies these assets and the starter HTML loads the helper before the project choreography script. It exposes icon/svg/path/draw/reveal/move functions with explicit nodes and times. Inspect assets/visual-kit.html before extending the family. Project-specific diagram geometry stays in the project; the text-block schema is not a general scene-graph API. Validate custom geometry and cue order in-browser and describe it in the storyboard, rather than inventing text events for it.

# Advanced Geometry Formulas

## 1. Neural Network (Dense Layers)

For visualizing AI models.

- **Layer Gap**: `200` (Horizontal space between layers)
- **Neuron Gap**: `60` (Vertical space within layer)
- **Connections**: Iterate every node in Layer `L` to every node in Layer `L+1`.

---

## 2. Orthogonal Paths (ERD / Circuits)

For connecting entities with right-angle lines.

**Path Logic**: `"M x1 y1 L x2 y1 L x2 y2"` (Horizontal first, then Vertical)
- **Midpoint**: Identify a "turning point" to avoid collisions.

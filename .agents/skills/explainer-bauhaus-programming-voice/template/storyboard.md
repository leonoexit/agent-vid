# Clause-to-picture storyboard

Starter example, replace for the requested topic. One dot = one nonnegative integer unit. Enclosure = a full group of three. The picture illustrates remainder, not processor internals. Question: what does 7 % 3 return?

| Beat | Cue / spoken task | Before → action → after | Focus and reading task |
| --- | --- | --- | --- |
| Hook | percent-sign phrase | geometric poster → show 7 % 3 = ? | Identify the question, keep unknown result hidden |
| Seven | gather, first, second | seven units → move 3 then 3 into enclosures | Track conserved items and full groups |
| Leftover | rest, result | one outside → inspect → show 7 % 3 = 1 | Distinguish remainder from number of groups |
| Change one input | add, rest, result | retain seven units → add one → show remainder 2 | Compare what changed and what stayed fixed |
| Exact fit | add, third, result | eight → nine → fill third group → remainder 0 | Empty remainder area explains zero |
| Rule | rule, limit | outcome → scope of the rule | Nonnegative integers, positive divisor |

For production add real cue times after TTS, before/action/after frames, code validation and limits. Reading holds must name what the viewer inspects. Scene names are not enough to score timing. Replace geometry and choreography when the new topic needs a different relationship.

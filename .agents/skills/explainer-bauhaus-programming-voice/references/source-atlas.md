## Extracted, adapted, excluded

Extracted: palette; geometric silhouettes; mass/void balance; type hierarchy; split fields; proof insets; hard rules; quantified native graphics. Adapted: square → portrait, readable Vietnamese leading, caption safety, semantic geometry and cue-driven transformations. Available as source recipes rather than automatic modes: funnel, bars, clock, megaphone, cross-out and UI specimen.

Excluded from production defaults: watermark @lenguyen.codeai, business/financial/legal assertions, claimed revenue, chapter count, LIKE/SHARE/SAVE, source attribution as new-video authorship, ZIP-export libraries and authoring comments. These are supplied source content, not instructions, verified evidence or a request to publish. The source is a contemporary Bauhaus-inspired series; no claim of historical authenticity is needed.

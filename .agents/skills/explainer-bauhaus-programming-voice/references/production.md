# Production with the existing runtime

`<skill>` is explainer-bauhaus-programming-voice. `<pipeline>` is its sibling explainer-bento-programming-voice, an explicit dependency for TTS and timing scripts only. Keep this dependency visible; if absent, report it instead of installing another renderer. The visual kit, story and example are independent of Bento.

1. From repo root, `source scripts/activate.sh`. Run `python <skill>/scripts/new-project.py projects/bauhaus/<slug> --language vi` (or en). Existing destinations are refused. Replace the sample using script.json, story.js and storyboard.md together.
2. Build the clause-to-picture plan before TTS. Choose shapes by meaning, source compositions by reading task, and native layers by what changes. Verify topic facts/code with primary sources or execution when needed, recording limits in facts.md.
3. Run `python <skill>/scripts/validate-script.py --project <project>`. It validates common text, story brief and cue anchors, not the semantics of project-authored JS. The bundled script uses sample-specific geometry; review that code separately after adaptation.
4. VI default: `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'`. EN: use the project's stored Kokoro setting without a Vietnamese override. Honor explicit/stored requests. Then `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. Changed narration invalidates audio and word timing. Resync even screen-only edits to update project-data.js.
5. For layout checks only, sync with `--music-only --no-bgm`. This has no voice and uses estimated cues; do not deliver it as a narrated production. Preview `index.html`; seek `window.__timelines['bauhaus-programming']`. The kit also includes `style-study.html` with static editable composition specimens, not a finished video.
6. Inspect settled type, accents, overflow, contrast, future-answer visibility, exact state and reverse seeks. Complete visual-review.md with actual intervals and observations. Listen across crucial spoken cues after TTS; token estimates are not listening evidence. `scripts/tests/browser-smoke.cjs` checks the bundled sample only and must not certify a different topic unchanged.
7. `hyperframes lint <project>` and `hyperframes check <project>`. Resolve runtime/cue/overflow errors; any intentional geometry extending beyond the canvas must be explicitly limited to decoration. Root/subcomposition editor warnings, if present, do not excuse actual clipping.
8. `hyperframes render <project> --quality high --fps 30 --output <project>/renders/<slug>-9x16.mp4`. Confirm 1080×1920, frame rate, audio, duration and full ffmpeg decode. Review the final MP4 at important boundaries and deliver a playable preview, stating actual remaining review limits.

Fonts and GSAP are local. There is no remote CSS, icon font, image or 3D dependency. Preserve bundled font licenses and the GSAP distribution's license header. No music is supplied. A user-provided track may be passed through the established pipeline; no social publishing or git push is implied.

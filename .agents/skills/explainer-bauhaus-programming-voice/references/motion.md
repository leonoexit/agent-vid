# Motion grammar for flat geometric evidence

Use short, controlled translations, group enclosure, alignment, mask reveals, clean field wipes and restrained scale changes. A piece should settle where its role is understandable. Avoid elastic overshoot on counted items, constant rotation, simulated handheld movement or floating backgrounds. Motion paths are simple enough to follow on a phone.

| Visual operation | Explanatory job | Guardrail |
| --- | --- | --- |
| Align or gather shapes | Expose correspondence or membership | Preserve IDs and count; do not hide rejected items without explanation |
| Move/copy a token | Transfer ownership or copy a value | Choose the correct semantic operation; retain source only for copy |
| Expand a bracket/region | Reveal scope, group or boundary | Do not let empty decoration imply actual containment |
| Replace one symbol/value | Change a condition and inspect consequence | Commit at the spoken/computed moment; preserve old evidence if compared |
| Strike and replace | Correct a tested interpretation | Show counterevidence first; avoid humiliating the learner |
| Reframe/field wipe | Change reading task | Retain a recognizable anchor; transition is not a model operation |
| Result enlarges | Inspect outcome | Keep the causal input/code available when needed |

Use phrase cues, not arbitrary percentages of a scene. `motion.js` resolves cues against actual word times; silent previews flag estimated timing. It exposes `appear` and `move`, plus a lightweight operation record for review. The record classifies authored operations; it does not prove they were correctly classified or that the explanation is understandable.

The template uses paused GSAP timelines registered with HyperFrames. Put state changes on the timeline using reversible sets/tweens; don't depend on mutable onComplete callbacks, wall-clock timers, random behavior, CSS autoplay or audio playback state. Preconstruct discrete text states and reveal them as appropriate; inspect arbitrary backward seeks. Keep captions in a stable zone independent of evidence reflow.

Before final render inspect important before/middle/after frames, content counts, result appearance and the longest intervals without new evidence. A held code comparison can be intentional. Record the viewer's task during that hold, or shorten narration/restage the explanation. Panning a static poster, pulsing a title or an animated progress dot does not resolve an unsupported hold.

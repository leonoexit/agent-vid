# Produce using the established HyperFrames pipeline

The sibling `explainer-bento-programming-voice` is an explicit dependency for its TTS and sync utilities only. No dependency on the Apple or Bauhaus skills at runtime: fonts and visual helpers are bundled here. If the voice pipeline is absent, report that dependency instead of installing another renderer.

1. `source scripts/activate.sh` from repo root. `python <skill>/scripts/new-project.py projects/mint-bento/<slug> --language vi` (or en). Destination must be new. Read template-contract.md, then adapt script.json/story.js/storyboard.md together.
2. Resolve the concept, audience, concrete example and clause-to-picture score. Verify code/claims when needed and record limits in facts.md. Choose panels by their explanatory job; don't require dates, charts or statuses just to resemble the source.
3. `python <skill>/scripts/validate-script.py --project <project>`. It checks common text and cue anchors, not correctness of arbitrary project JS or layout.
4. VI: `python <pipeline>/scripts/tts.py --project <project> --engine vieneu --voice 'Hải Đăng'`. EN: use stored local Kokoro settings without the Vietnamese override. Honor stored/explicit preferences. Then `python <pipeline>/scripts/sync-narration.py --project <project> --no-bgm`. Regenerate voice and timings after narration changes; resync screen-only script changes too.
5. `--music-only --no-bgm` on sync makes a silent estimated preview; it is not a narrated deliverable. Use MintUI components in story.js as well as in any new study so the preview reflects reusable implementation. Preview index.html and seek `window.__timelines['mint-bento-programming']`. `style-study.html` is a static editable composition sheet, not a complete video.
6. Inspect every important native operation, related view, reverse seek, text/diacritic, contrast, overflow and caption region. Listen across important spoken cues. Review unsupported holds and complete visual-review.md honestly. The bundled browser smoke test checks the push fixture; rewrite its state assertions for a different topic.
7. Run `hyperframes lint <project>` and `hyperframes check <project>`, resolve actual failures, then render when a video was requested: `hyperframes render <project> --quality high --fps 30 --output <project>/renders/<slug>-9x16.mp4`. Check dimensions, FPS, duration, audio, full ffmpeg decode and key boundaries in the MP4.

The HTML references local fonts, GSAP and icons. HyperFrames may additionally populate its own font cache during compilation. Keep font licenses and the GSAP distribution header. No background music is bundled; use the established pipeline for user-provided audio. Creation of a skill doesn't imply a video test, external publishing, commit or push.

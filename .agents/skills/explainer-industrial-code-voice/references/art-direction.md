# Industrial technical-grid adaptation

The source is a 44-slide, 1200×1200 static carousel about mathematical infinity, computation and Gödel. This skill
adapts its visual system to a narrated 1080×1920 programming explainer. It does not inherit the source's subject,
claims, branding, watermark, CTA, slide count, square canvas or static-export instructions.

| Source pattern | Motion-video treatment |
| --- | --- |
| `#121212` field with 100px grid | Persistent dark technical board behind all scenes. |
| Space Grotesk display and Inter body | Bundled local fonts; IBM Plex Mono remains reserved for code/data. |
| Thin `#444` rules and industrial cards | Squared modules with one-pixel borders, corner ticks and no soft glass effects. |
| Figure IDs, status tags and page footers | Scene kicker, FIG counter, series tag and progress rail. |
| Lists, matrices, trees and process diagrams | Native HTML/SVG state models that can update and be reverse-seeked. |
| Red diagonal/error marks | Red only for the active operation, contradiction, error or exception. |
| Giant outlined/background numerals | Optional low-contrast scene index, kept outside the content hierarchy. |
| White `TRUTH / PROOF` inversion | Rare conclusion or conceptual split; do not alternate palettes casually. |
| `NO ANIMATION` static-export CSS | Source-local instruction; motion here is required and meaning-bearing. |

The stable composition has five protected vertical zones: system header, title stack, 860×570 model, code strip and
takeaway, then captions/footer. The grid and outer frame do not drift. Animate the model with short linear or controlled
ease transitions: draw a relation, move a token, flip a bit, fill a cell, or update a status. Avoid soft floating,
bouncy cards, glass blur and decorative parallax; they conflict with the measured industrial tone.

Generated art may appear as quiet background texture, decoration or a contextual figure in its own zone. Technical
labels, code, data, cells and arrows stay native and legible without that image.

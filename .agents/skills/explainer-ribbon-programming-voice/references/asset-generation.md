# A coherent generated asset family

Use built-in imagegen through the imagegen skill for raster assets. Use native SVG/text where simple ribbons, precise arrows, logical connectors, labels and small geometric marks need independent control. A stable generated plate may contain these elements after accuracy review. Do not substitute generic SVG clip art when the storyboard actually calls for a rich generated illustration.

## Shared style brief

Playful editorial imagery; choose flat illustration, matte shallow-depth props, a photographic context window or a whole composition according to its job. For the illustrated family: strong organic evergreen silhouettes; pale-pink/ivory contour details; citrus or orange accents; simplified human poses when a human action is relevant; restrained analog irregularity; readable at phone scale. Avoid glossy product-render 3D, heavy shadows, neon, glass or competing art styles. Realistic hardware/human photography can serve context; matte 2.5D props can serve a metaphor. Both should retain the editorial color/composition family. Rich detail should support the subject, not fill every shape with ornament.

Palette anchor: evergreen #00624C, blush #F0C6E5, ivory #F7F4ED, citrus #CED443; orange #FF702E and blue/sky only as selected accents. Use a consistent dominant ink across a family rather than requiring all colors in every asset.

## Distinct asset roles

**Pictorial icon:** one recognizable object/action with a strong silhouette and very few internal details, isolated cutout. Keep it identifiable at its actual display size. Generate each final icon as a separate asset rather than an unlabeled collage that requires fragile cropping.

**Recurring visual anchor:** one subject/object used across related shots. Establish its shape, orientation and identity colors; use the approved output as a reference for later variants. If parts move independently, generate separable parts with consistent perspective and empty margins. A native number chip should not be baked into the bitmap.

**Explanatory illustration:** a larger scene or metaphor with a specific narrative job. Limit competing subjects; leave negative space for native labels. Explain the metaphor's mapping and limits. A workshop can evoke a transformation rule but is not a literal function execution model.

**Context photograph:** both source sets contain photographic imagery; the user identifies the new whole frames as generated, so do not assert their photos were shot or sourced separately. Use only when the actual concept benefits from a real setting or human context. Frame it with a large rounded crop; it should not become generic lifestyle decoration or replace the illustrated family without a reason.

**Whole composition plate:** a deliberately designed frame with a dominant headline/glyph, integrated ribbon and image hierarchy. Suitable for a stable hook or recap, not a default for a changing mechanism. Generated text is allowed when exact and visually checked; important code/data still need independent layers if they change.

**Layered editorial plate:** context/background with purposeful empty regions for native type and exact evidence; separately generated moving objects preserve the same perspective, light and palette. This allows gen-img to provide the richer visual treatment without flattening the explanation.

## Prompt scaffolds

Icon: “One [object/action], flat editorial pictorial icon, coherent organic evergreen silhouette, ivory and blush line details, one citrus accent, simple readable shape, generous transparent margin, no text/numbers/labels/logos, no gradient/shadow/3D.”

Anchor: “One [subject with role], [identity and orientation], flat editorial studio illustration, evergreen/blush/ivory/citrus palette, restrained irregular contours, [separate parts or blank areas for native data], transparent background, complete unclipped silhouette, no lettering or code.”

Scene: “A [specific situation that explains this clause], [one dominant relationship], flat playful editorial illustration with organic green forms and limited pink/citrus accents, strong reading path, space for native text, no pseudo-diagrams or generated lettering.”

Do not copy these placeholders literally. Include the subject, intended display size, purpose and continuity constraints. For isolated assets request real transparency; for scenes state the desired backdrop. Do not rely on chroma-keying a white background later.

## Review and provenance

Inspect pixels, alpha, silhouette, unwanted text, color compatibility, crop and the semantic role. Check icon legibility at its final size. Save the final prompt, tool/mode, output path and role in asset metadata. Keep image-generation output in the workspace before referencing it in production. Rejected variants are not automatically part of the reusable library.

The bundled workshop is a style/anchor sample for the function example, not a universal mascot. Generate a fitting subject for other concepts. Its generation prompt and review are recorded in assets/illustrations/workshop.json. Do not imply acceptance across all topics from this one asset.

## Additional prompts from the new reference

Whole-frame starting brief: “A 9:16 Vietnamese programming explainer opening poster about [specific question]. One dominant [word/number/symbol], exact short headline [approved text], [one supporting visual relationship]. Heavy editorial sans with generous space for Vietnamese diacritics; [chosen ivory/evergreen/blush/sky field], selective orange emphasis, broad segmented ribbon integrated with the reading path. [Flat illustration / matte shallow-depth metaphor / rounded photo window] as the secondary focus. Maintain a clear portrait hierarchy and room for captions below. No website branding, watermarks, page counters or invented code. Every visible word must be exactly as specified.” Validate the output; the prompt does not guarantee correct lettering.

Layered scene starting brief: “A portrait editorial scene for [spoken clause], inspired by the supplied Ribbon reference. [Main subject and visual relation], ivory/evergreen/blush with [one accent]. Matte shallow relief / photographic context as selected, restrained depth, no glossy ceramic app tiles. Leave [explicit region] calm for a native headline and [region] blank for exact values. [List moving parts] must be supplied as separate cutouts in follow-up generations using this scene as a continuity reference. No text, pseudo-code or diagrams in these blank areas.” Do not ask one output to magically provide multiple separable layers.

Type-object starting brief: “One [large symbolic glyph or abstract text-free prop] as the hero, editorial scale, [flat/matte cut-paper depth], [specific palette], full uncropped subject with clean transparent margins, no incidental lettering.” Use native type instead when a precise accent, operator shape or changing value is the lesson.

These are briefs, not a mandate to gen-img every element. Use the imagegen tool with the actual selected reference image(s), not only a textual mention of their filenames. Inspect a local reference before editing it. For fresh outputs inspired by the references, request a new original composition; do not reuse their watermark/branding as an asset or strip it from reference copies. Reference source material remains intact.

For generated text, inspect every Vietnamese accent, spelling, line break and exact symbol at full size and phone scale. If a critical label is wrong, regenerate/edit with imagegen, or generate a clean text-free region and place verified native lettering. Keep the asset's prompt and chosen generation mode in provenance. Never accept a false numeric/code result just because the poster is attractive.

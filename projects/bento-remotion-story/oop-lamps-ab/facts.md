# Factual scope

OOP groups related state and behavior in objects. This video introduces class-based OOP using Python, not every OOP system or all four commonly taught principles. A class defines a type of object; two calls to Lamp() construct distinct instances. self.on is instance data; self denotes the receiver in these methods. turn_on changes only that receiver here. Objects can share referenced data in other programs; we do not claim universal independence. Python attributes are not made private by this example.

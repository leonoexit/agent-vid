# Sources — checked 2026-10-09

1. Git / Pro Git, A Short History of Git: https://git-scm.com/book/en/v2/Getting-Started-A-Short-History-of-Git
   Units 1–5, 7: Linux used BitKeeper from 2002; free-of-charge status revoked in 2005 after relationship breakdown; this prompted the community, especially Linus, to develop its own tool. Design goals: speed, simple design, parallel branches, distributed, efficient at Linux scale. Original narration paraphrases; no invented quote or claim Linux stopped operating.
2. Git's first commit: https://github.com/git/git/commit/e83c5163316f89bfbde7d9ab23ca2e25604af290
   Unit 5: first recorded revision by Linus Torvalds, 7 April 2005. Not presented as the date of a polished public release, nor a claim he completed modern Git in one day. On-screen author/date/hash are typeset evidence metadata, not an invented screenshot.
3. Git / Pro Git, About Version Control: https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control
   Unit 6: ordinary distributed clone mirrors repository history; local work and subsequent collaboration. Qualifier “cách sao chép thông thường” excludes shallow/partial clones. No claim that Git alone prevents all data loss.

Editorial: free usage withdrawal is the triggering event, not the only design motivation. No unsupported dramatic deadline, theft allegation or monopoly claim. Modern Git's success/market share is not asserted. “Cộng đồng tự phát triển” is paraphrase of the own-tool response, not exclusive sole authorship.

Visuals: all generated computer/penguin/paper/hands/headline assets are stylized illustrations. Penguin is a symbolic Linux association, not authentic Tux art. No generated face of Linus, archive photograph or faux historical document. Native labels identify BitKeeper and Linus. Sources support narrative facts, not the generated props' historical accuracy.

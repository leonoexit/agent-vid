# Pop Narrative trial — Git origin

Format: causal documentary short; Pop visual grammar, Hải Đăng, no music/SFX. Voice connects decisions and consequences. Color plan: yellow is the opening/question stage, purple separates collaboration context, coral/pink marks loss, cyan marks construction. Return to yellow for the answer. Colors supply contrast and narrative chapters, not a universal emotion code.

1. Opening: visible “VÌ SAO / GIT / RA ĐỜI?” with computer and Linux penguin. A paper free-use ticket is pulled away on “mất quyền”; headline Git arrives as the consequence. No first-frame ambiguity.
2. Context: reuse computer, collect three paper change pieces from separate positions into one source bundle. Native BitKeeper label identifies the tool; images show cooperation, not fake app UI.
3. Trigger: the free-use ticket splits from the tool assembly and leaves the frame; a short “2005 / DỪNG MIỄN PHÍ” label anchors the event. Computer remains; avoid suggesting software or source disappeared.
4. Requirements: source papers split into parallel work lanes; fast paper movement settles into readable “Nhanh / Nhiều nhánh / Phân tán” states at the corresponding clauses. Not a terminal tutorial.
5. Response/evidence: photographic typing hands, Linus name label, generated Git headline. Uncover typeset actual first-commit metadata on the date phrase. Date/hash are evidence; typing hands are illustration.
6. Consequence: computer copies into three smaller positions, each gets the same three-layer history bundle; a new change appears locally, then copies toward the others. This is a simplified collaboration illustration, not literal Git transport internals.
7. Payoff: the main computer, source bundle and Git headline reunite. Text “Cộng tác tiếp. / Ở quy mô lớn.” resolves the opening. No engagement-bait cliffhanger.

Asset coverage: computer anchors 1/2/3/6/7; penguin establishes Linux in 1/7; paper source bundle changes relationships in 2/4/6; typing hands stages creation in 5; generated GIT lettering is a headline and cover subject. Existing backplates hold short labels. Exact history/date/hash and variable source pieces remain native. No generated backgrounds.

Motion: moving paper assemblies, staggered purposeful state changes and bounded stepped wiggle. Captions stable. Carry anchors across 1–3, and 5–7; palette changes and cuts mark actual story shifts, no flash or transition sound. No universal giant canvas.

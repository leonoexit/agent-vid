# Terminal — Code Noir visual revision

This revises the visual score against the existing 94-second narration. Narration, timings, caption-display mappings and voice settings are identical to terminal-la-gi. Original files/render remain intact. The inherited timings are estimated word timings, not newly aligned audio.

| Section | Explanatory asset / anchor | Development during the voice |
|---|---|---|
| Question | Terminal frame, prompt, folder silhouette | ls appears, directory names appear, then the question asks which location they belong to. |
| Terminal vs shell | Terminal frame + labelled software participant | Command moves toward shell; a returning connector introduces visible output. This is a conceptual model, not an exact process architecture. |
| Current directory | Pink location pin above /Users/an | pwd identifies location; ls reveals and connects Desktop/code children. |
| Argument | Same directory tree and command tokens | Distinguish command name from argument; select code branch, reveal hello.c as output. |
| Relative path | Same pin and tree, path components | Current-directory prefix joins the provided segment; selected branch shows what that means. |
| Absolute path | Add root / to the same tree | Relative trace begins at the pin; absolute trace begins at /. Windows path is an illustrative notation note. |
| cd + same command | Move pink pin from an to code | ls code now seeks a child named code; dashed missing target and cross explain the existing error output. |
| Recall | Preserve pin at code, show pwd | Location/output /Users/an/code answers where the shell is currently operating. |

SVG assets are from the updated reusable Code Noir kit. Diagram geometry and phrase cues are project-owned native HTML/SVG/GSAP. The tree models the simplified example already narrated, not the whole filesystem. Spelling maps remain caption-only; motion cues use spoken phonetic text.

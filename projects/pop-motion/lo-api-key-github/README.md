# Lỡ push API key lên GitHub

A 43.9-second vertical Pop Motion short for beginning programmers who know commit/push.

- Video: `renders/lo-api-key-github-9x16.mp4` — 1080×1920, 30fps, H.264/AAC.
- Facebook cover: `cover/lo-api-key-github-1080x1920.jpg` plus PNG and crop previews.
- Script: `script.md`; claim map: `sources.md`; staging plan: `storyboard.md`.
- Voice: Hải Đăng, local VieNeu, original speed; no music or SFX.
- Corose headings, original JetBrains Mono paper/body copy, Inter UI/captions.
- Minimal generated hand-drawn stick figure replaces the rejected detailed comic-person direction. Physical photographic key is a metaphor for a credential's access, not a diagram of cryptography.
- All UI and credential strings are fictional simulations. No real API credentials used or changed.

Built with the experimental Pop Motion skill and local HTML/CSS/GSAP/HyperFrames. The user authorized this applied incident explanation; it is a content trial rather than a claim that Pop's discovery format should become a full software tutorial. Stable Pop variants and prior projects remain unchanged.

New generated assets have exact prompts in `assets/stick-viewer.json` and `assets/brass-key.json`; both created with built-in imagegen and registered in the shared Pop library. Installed local copies and provenance are in `library-assets.json`. Corose retains the supplied personal-use font provenance; commercial rights are not asserted.

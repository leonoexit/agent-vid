# Image-led test — project only

User direction: test before updating any skill. Preserve Pop palette/materials/Corose and the same 43.88s narration for a staging comparison. Borrow Vox's sentence-to-image beats and causal object assembly, not its aged-paper palette, required sounds/music, renderer or global skill edits.

Visual story:
1. A key lies on a physical stack of source code posted under the GitHub label. An eraser rubs away that key mark, then a puzzled minimal stick figure reacts. Opening identifies API key/GitHub without relying on post context.
2. The clean new stack is pulled aside; an older stack slides out from behind, still carrying the identical key. Labels only identify current versus old commit. No code window or explanatory paragraphs.
3. The key leaves the old paper and duplicates into a separate copy. The papers disappear but the copy remains and approaches the lock, which opens. Copying is hypothetical in narration.
4. The same lock stays in view. A small contextual revoke action is pressed; the lock closes and both old keys fade to inactive grey. A copied key tries again, recoils, and fails. The lock is a visual metaphor for validity, not literal cryptography or a claim that all secrets grant all access.
5. A new labeled key opens the lock. A printed usage receipt rolls into view; a magnifier traverses its rows. Once audit is established, a small code stack is cleaned up. New key/update, audit and cleanup remain in narrated order.
6. A clean paper/eraser and a closed lock/disabled key share the frame. Short final phrase “Xóa ≠ Thu hồi” anchors the conclusion; the images show the two different jobs.

Voice tells the logic. Imagery performs actions and preserves objects across beats. No per-scene paragraph/heading, generic chart, full UI dashboard or background generation. Karaoke remains an accessibility layer, not the main image. Native text is only the initial hook, short identity labels, the revoke control and closing distinction. Native lines/status marks allowed where they convey an actual relation or result.

New assets: eraser; matching closed/open padlock; transparent-lens magnifier; curled USAGE receipt. Reused: source code paper, brass key, pointing hand, minimal stick figure and paper labels. Each chosen for a needed action, no asset quota. Exact prompts/provenance are in assets/*.json and library-assets.json. Originals unchanged; CSS clipping removes only transparent margins at presentation time.

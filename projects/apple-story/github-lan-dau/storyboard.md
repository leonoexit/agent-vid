# GitHub lần đầu · repo + commit — storyboard

Apple-inspired vertical explainer (1080×1920, 30 fps) · Hải Đăng, speed 0.9, paragraph gap 0.45 s · ~132 s.
Audience: chưa biết gì về code, mở GitHub lần đầu, đã có tài khoản, thao tác trên web. Không cần Git/terminal.
One concept (repo + commit = ngăn dự án + điểm lưu), one worked example (repo `banh-chuoi`, README 2 → 3 quả chuối).

## Visual identities (constant through the video)

| Thing | Picture |
|---|---|
| GitHub | blue ceramic tile, cloud glyph (no logo) |
| repo | violet: tile (intro/outro) and sculpted folder `banh-chuoi` with lock (Private) |
| README.md | white paper card / editor; the quantity digit is amber, bananas = quantity |
| commit | numbered deep-teal bead (1, 2, 3) on a grey history rail, label = message + time |
| not committed | dashed amber pill "Chưa vào lịch sử", dashed coral ghost bead `?` |
| GitHub UI | glass browser mock labelled "GIAO DIỆN MINH HỌA · RÚT GỌN" |

## Contexts

| Section | Context | Key state change |
|---|---|---|
| intro | jargon cloud | 10 English terms → only `repo` and `commit` remain as tiles; banana = example |
| 1 | devices + cloud | recipe chip uploads from laptop into GitHub; second device gets it ✓ |
| 2 | repo folder | folder appears under GitHub, file slides in, clock badge = history |
| 3–4 | browser mock | + → New repository → type `banh-chuoi` → Private, Add README on → Create |
| 5 | repo + README + rail | README leaves the folder; rail draws; bead 1 `Initial commit` (automatic) |
| 6 | editor | pencil → editing; type `2 quả chuối`, 2 bananas |
| 7 | editor + dialog | "Chưa vào lịch sử" + ghost slot; Commit changes → message `Thêm công thức` |
| 8 | editor + rail | message + time chips; flash snapshot flies to slot → bead 2, "Đã lưu" |
| 9 | editor + rail | digit 2 flips to 3, third banana; draft again → commit → bead 3 `Thêm chuối` |
| 10 | Commits list | beads move into rows, newest on top; highlight message / who / when |
| 11 | diff | bead 3 opens: red `- 2 quả chuối`, green `+ 3 quả chuối` |
| 12 | rail + task | **1.6 s prediction hold**: is the 2-banana version still there? |
| 13 | rail + snapshots | ✓; opening bead 2 shows the whole old file with 2 quả; all beads glow |
| 14 | rail + draft | uncommitted `4 quả` draft has no bead (ghost ✕) and fades; Commit button |
| outro | rule | repo tile "ngăn chứa dự án", commit tile "điểm lưu có ghi chú", rail stays |
